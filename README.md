# covid_vaccination_analysis
Performing descriptive statistics and data visualization on COVID-19 datasets. Features an interactive world map to track infection levels per capita, leveraging Python for epidemiological investigation and trend analysis.
📌 Project Overview
In the history of mankind, epidemiological investigations and transparent data disclosure have played a vital role in developing vaccines and treatments. This mini-project conducts a descriptive statistical analysis of the global COVID-19 pandemic to understand the distribution of infections and the impact of vaccination efforts.

The goal is to transform complex public health data into an intuitive world map visualization, allowing anyone to check the cumulative infection levels at a glance.

🎯 Key Objectives
Trend Analysis: Identify which countries have the highest number of cumulative infections.

Geographic Visualization: Display infection levels on a global map for easy comparison.

Insight Generation: Explore the relationship between vaccination doses and the spread of the virus.

Data Transparency: Highlight the importance of publicly released data in managing global health crises.

📊 Data Source
Primary Source: Our World in Data - Real-time Coronavirus (COVID-19) Vaccinations database.

Dataset Used: covid-vaccination-doses-per-capita.csv

Note on Data Quality: This analysis acknowledges that some countries do not disclose full data. These regions are excluded or handled as missing values to maintain the integrity of the practice.

🛠️ Tech Stack
Language: Python

Libraries: * Pandas / NumPy (Data Manipulation)

Matplotlib / Seaborn (Statistical Visualization)

Folium or Plotly (Geospatial Mapping)

Environment: Jupyter Notebook

📈 Analysis Workflow
Data Cleaning: Handling missing values and filtering data by date and region.

Descriptive Statistics: Calculating cumulative totals and infection rates per capita.

Exploratory Data Analysis (EDA): Identifying regions where infection rates are decreasing.
